# Quran Ayah Correction Chatbot

An intelligent NLP-based chatbot for detecting and correcting errors in Quranic verses using Arabic text preprocessing and similarity matching techniques.

---

## Overview

This project focuses on building a Quran Ayah Correction System that can:

- Detect incorrect Quranic verses
- Suggest the closest correct Ayah
- Compare user input against authentic Quran text
- Handle Arabic text normalization and preprocessing
- Evaluate correction accuracy using similarity metrics

The project combines:

- Natural Language Processing (NLP)
- Arabic text preprocessing
- String similarity algorithms
- Information retrieval techniques

---

## Features

- Arabic text normalization
- Quran verse matching
- Error correction suggestions
- Similarity scoring
- Evaluation pipeline
- Interactive notebook experiments
- Modular Python scripts
